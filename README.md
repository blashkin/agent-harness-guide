# Анатомия обвязки агента

Учебник о том, как Claude Code собирает сессию из инструкций, скиллов, хуков и MCP, сколько это стоит и как собрать свою обвязку поверх командной.

Читать: https://blashkin.github.io/agent-harness-guide/

16 листов в трех частях:

- Механика - контекст, кэш и деньги, инструкции и память, скиллы, сабагенты, хуки, MCP, настройки, Desktop и CLI, харнесс.
- Проект - кто за что отвечает, своя обвязка поверх командной, стоимость, как поддерживать обвязку.
- Решение - как не засорять сессию и какой клиент выбрать.

Цифры в примерах - 139 сессий одного разработчика за 19.06-28.09.2026, цены Anthropic API на 24.06.2026.
