# Анатомия обвязки агента

Учебник о том, как Claude Code собирает сессию из инструкций, скиллов, хуков и MCP, сколько это стоит и как собрать свою обвязку поверх командной.

Читать: https://blashkin.github.io/agent-harness-guide/

16 листов в трех частях:

- Механика - контекст, кэш и деньги, инструкции и память, скиллы, сабагенты, хуки, MCP, настройки, Desktop и CLI, харнесс.
- Проект - кто за что отвечает, своя обвязка поверх командной, стоимость, как поддерживать обвязку.
- Решение - как не засорять сессию и какой клиент выбрать.

Цифры в примерах - 139 сессий одного разработчика за 19.06-28.09.2026, цены Anthropic API на 24.06.2026.

## Главное за минуту

1. Реплика - не один запрос, а цикл. Каждый шаг заново отправляет весь контекст, но неизменное начало читается из кэша.
2. Кэш ломают смена модели, `/compact`, пауза дольше TTL и включение fast mode. TTL - 1 час на подписке и 5 минут по API. Смена effort на Opus 5.5, Sonnet 5.5 и Fable 5.1 кэш не ломает.
3. Правка CLAUDE.md посреди сессии не действует до `/clear`, `/compact` или перезапуска.
4. Постоянный контекст - инструкции, листинг скиллов, память - оплачивается в каждом запросе, десятки раз за сессию.
5. Claude Code и claude.ai живут раздельно: чаты и Cowork делят память и инструкции, Claude Code не видит ни того, ни другого.
6. Скилл в контексте - это только описание. Плохое описание, и скилл не вызовется.
7. Сабагент возвращает только отчет - самый дешевый способ прочитать много.
8. Хук - единственный способ сделать что-то гарантированно.
9. MCP грузятся лениво, в запросе только имена инструментов. CLI сервиса часто дешевле MCP.
10. Desktop дороже CLI на 20-30k в каждом запросе, а по API-ключу Desktop не работает.
11. Главный рычаг экономии - короткие сессии.
